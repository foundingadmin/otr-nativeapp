# Project rules (persistent)

These apply to every conversation in this project.

## Never delete design work
- **NEVER delete exploration files or boards.** When an exploration is retired, ARCHIVE it: move the folder into the workstream's `archive/` directory and add a `LEDGER.md` entry naming the decision that closed it.
- This applies to any design or exploration artifact. Deleting is not allowed — archiving preserves the decision trail. If a comment says "remove this," it means remove the specific element referenced, never delete a whole file or folder without explicit, unambiguous instruction to delete that exact path.

## Copy
- **No em dashes anywhere** (board copy or product microcopy or code). Use commas, periods, semicolons, or `•`. See `docs/LESSONS.md` for the full board-copy language rules.
