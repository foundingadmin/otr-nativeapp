Canon Export

The export station between this design surface and Figma. It walks each board's rendered artboards, emits a Figma-ready IR (layout, paints, strokes, radii, effects, text) with every colour already carrying its Figma variable decision, and writes the result into handoff/spec/ir/. Run it whenever a board changes, before handing the pack to Claude Code.
