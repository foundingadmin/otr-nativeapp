# DR-X-004 — No "hard-stop" status; titled needs-attention form

**Date:** Jun 23, 2026 · **Verdict:** adopt · **Status:** ✅ integrated

**Decision:** "Hard-stop" is dropped as a concept. A required action on an otherwise-steady case is *Active + the titled/needs-attention badge form* — never a status change. Form + weight carry the triage: light fill = ambient, solid fill = act now, titled = "this case wants you."

**Provenance:** Badge board feedback; codified with DR-X-006.

**Integration:** Core badge component (`cases/_ds-cases/kits/core-kit.jsx`) titled/straight variants; needs-attention cards in feed + detail boards.
