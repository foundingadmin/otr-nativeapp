# DR-X-003 — Conclusion language: Resolved macro, Dismissed! override

**Date:** Jun 23, 2026 · **Verdict:** adopt · **Status:** ✅ integrated

**Decision:** **Resolved** is the single macro state for any case conclusion. **Dismissed!** overrides it when the outcome is favorable (the win — solid green + confetti). **Settled** is removed from the language entirely; **Won** is retired/renamed to Dismissed!. The badge *is* the result — no separate outcome banner.

**Provenance:** Badge board feedback reconciliation (PRD v1.2 → v1.4).

**Integration:** registry boards in `cases/system-case_status_and_action/`; Series-3 cards across feed + detail boards.
