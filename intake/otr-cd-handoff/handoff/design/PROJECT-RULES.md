# CD project rules (mirror of the design project's CLAUDE.md)

These are the rules the Claude design project runs on. They are reproduced here because the file they normally live in is a reserved name. `../CLAUDE.md` at the pack root carries the rules for the Claude Code repo, which extend these.

## Never delete design work

- **Never delete exploration files or boards.** When an exploration is retired, archive it: move the folder into the workstream's `archive/` directory and add a `LEDGER.md` entry naming the decision that closed it.
- This applies to any design or exploration artifact. Deleting is not allowed; archiving preserves the decision trail. If a comment says "remove this," it means remove the specific element referenced, never a whole file or folder without explicit, unambiguous instruction to delete that exact path.

## Copy

- **No em dashes anywhere** (board copy, product microcopy, or code). Use commas, periods, semicolons, or `•`. See `docs/LESSONS.md` for the full board copy language rules.
