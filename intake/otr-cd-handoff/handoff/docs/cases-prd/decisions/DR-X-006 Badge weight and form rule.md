# DR-X-006 — Badge weight + form as governing DS rule

**Date:** Jun 23, 2026 · **Verdict:** adopt · **Status:** ✅ integrated

**Decision:** Fill weight = attention demand (light/tinted = ambient: Incomplete, Analyzing…, Active, Resolved; solid = act-now/peak: Deadline, SmartMatch'd, Almost gone, Expired, Dismissed!). Form = default vs. needs-attention (straight vs. titled). Dotted outline = Series-1 unfinished. This is the mechanism of feed triage — in a feed of light badges, solid/titled pops before a word is read — and it reinforces the feed sort (PRD §11.4).

**Provenance:** Badge board Series 1–3 + feedback; codified PRD v1.4 §6.1.

**Integration:** `cases/_ds-cases/kits/core-kit.jsx` badge primitives; documented on `cases/system-case_status_and_action/Case Status and Action.html`.
