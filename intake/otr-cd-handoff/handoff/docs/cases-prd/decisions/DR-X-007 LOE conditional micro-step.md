# DR-X-007 — LOE as conditional, state-gated micro-step

**Date:** Jun 23, 2026 · **Verdict:** adopt · **Status:** ⏳ decided — integration pending

**Decision:** The Letter of Engagement fires only *after* quote acceptance, only where the customer's state (and fee threshold) requires it. Never a blocking status badge — surfaced as a required action via the titled needs-attention form on Active (DR-X-004). One-tap e-sign; re-sign on reassignment is a one-tap re-confirm highlighting only the new attorney. Pre-empt where the state is known.

**Provenance:** PRD v1.4 §7.7 incl. preliminary LOE legal research (CA $1,000 / NY $3,000 thresholds; MA/CT/DC universal — low-% scenario for traffic matters; non-legal-advice, OTR to confirm).

**Integration debt:** LOE required-action UI (CPC + detail + re-sign moment) not yet designed → ROADMAP Next #2. Open dependency: confirm exact state list (PRD §15).
